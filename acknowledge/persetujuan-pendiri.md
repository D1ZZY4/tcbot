# Persetujuan Pendiri

Pernyataan persetujuan para admin grup pendiri terhadap aturan TCF. Dicatat di grup koordinasi admin TCF.

## Pernyataan

Disepakati oleh para admin grup pendiri dan dicatat dalam grup koordinasi admin TCF, pada tanggal [ ... ].

Daftar grup pendiri dan admin yang menyepakati:

1. [ nama grup Telegram ] , admin: [ nama pengguna ]
2. [ nama grup Telegram ] , admin: [ nama pengguna ]
3. [ nama grup Telegram ] , admin: [ nama pengguna ]

## Catatan

- Persetujuan ini jadi dasar berlakunya aturan bagi grup pendiri sejak diumumkan di kanal resmi dan tersedia di grup.
- Grup keluar dari TCF tidak menghapus perkara yang sedang berjalan.
